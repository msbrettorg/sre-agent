Source and calculation

Kusto target: not configured.

Live path: this single-file report calls the hosted window.sreagent.callTool Kusto and Azure benefit tools. There are no external modules, browser credentials, localhost API dependencies, or saved-result fallbacks.

Observed source: Costs(), CommitmentDiscountType == 'Savings Plan', ChargeCategory == 'Usage', and reported Used or Unused commitment-discount status. These are cost-allocation statuses, not plan lifecycle statuses.

Only observed 7-day and 30-day utilization is calculated. Cost rows do not establish current purchased-plan inventory, active status, contractual hourly commitment, term, or expiry. Those fields require authoritative Azure Billing data and remain unavailable here.

Azure Benefit Recommendations are requested at MCA billing-profile scopes discovered from Costs(), for Shared scope, P1Y/P3Y terms, Last30Days and expand=true. The modeler uses only returned allRecommendationDetails alternatives. Azure estimates are not guaranteed savings. Daily Azure benefit utilization excludes the current UTC day. Missing or invalid values remain unavailable. Purchased-plan inventory and customer price-sheet eligibility are not supplied by these operations. No purchases or Azure configuration changes are performed.
