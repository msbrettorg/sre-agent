Observed utilization = Used EffectiveCost / (Used + Unused EffectiveCost), excluding purchases. Windows end at today's UTC midnight and include only reported cost rows, which can be delayed or revised. Missing rows are not filled with zero. A zero denominator or invalid cost makes the percentage unavailable. Currencies, accounts, and billing profiles remain separate.

Source and calculation

Kusto target: not configured.

Live path: this single-file report calls the hosted window.sreagent.callTool Kusto tool. There are no external modules, browser credentials, localhost API dependencies, or saved-result fallbacks.

Observed source: Costs(), CommitmentDiscountType == 'Savings Plan', ChargeCategory == 'Usage', and reported Used or Unused commitment-discount status. These are cost-allocation statuses, not plan lifecycle statuses.

Only observed 7-day and 30-day utilization is calculated. Cost rows do not establish current purchased-plan inventory, active status, contractual hourly commitment, term, or expiry. Those fields require authoritative Azure Billing data and remain unavailable here.

Azure Benefit Recommendations and customer price-sheet eligibility are not loaded by this Kusto-only report. Purchase modeling and coverage remain explicitly unavailable, rather than substituting discounts or synthetic scenarios. No purchases or Azure configuration changes are performed.
